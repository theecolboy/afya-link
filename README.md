# AfyaLink Healthcare System

A modern healthcare system built with React and Node.js.

## Project Structure

```
afyalink-system/
├── frontend/          # React + Tailwind CSS frontend
├── backend/           # Node.js + Express backend
└── README.md
```

## Tech Stack

- **Frontend**: React.js + Tailwind CSS
- **Backend**: Node.js + Express.js
- **Database**: MongoDB
- **Authentication**: JWT

## Getting Started

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```

## Features

- Authentication
- Dashboard
- Appointments
- Emergency System
- Telemedicine
- Insurance
- Wellness
- Marketplace

## Deployment

- Frontend: Vercel or Netlify
- Backend: Render or Railway
- Database: MongoDB Atlas
